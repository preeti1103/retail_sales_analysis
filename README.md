# Retail Sales Analysis

## Overview
This project analyzes Walmart’s sales data to identify:
- Top & bottom performing stores
- Impact of holidays and monthly seasonality
- Yearly growth trends
- Sales forecasting (next 4 weeks baseline)
- Influence of external factors (Fuel, CPI, Unemployment)

## Dataset
- Source: [Kaggle Walmart Sales Dataset](https://www.kaggle.com/datasets/yasserh/walmart-dataset)
- Columns: Store, Date, Weekly_Sales, Holiday_Flag, Temperature, Fuel_Price, CPI, Unemployment

## Tools & Libraries
- Python, Jupyter Notebook
- Pandas, Matplotlib, Seaborn
- Statsmodels

## Key Insights
- Top 5 stores generate ~30% of total sales; bottom 5 <5%.
- Holiday weeks boost sales by ~7–10%.
- December shows consistent peak sales.
- 2011 was the peak year; 2012 sales declined ~20%.
- Forecast baseline: ~$47M per week.
- External factors show weak correlation → focus on seasonality.
